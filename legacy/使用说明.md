# 高考学习训练系统（简化版）使用说明

单机桌面应用：tkinter 图形界面 + Excel 数据文件，无需 Web Server、无需数据库。

## 一、运行环境

- Windows 电脑，Python 3.10 及以上（tkinter 为 Python 自带）。
- 首次使用前安装依赖（联网一次即可）：

```bash
pip install -r requirements.txt
```

## 二、启动

- 双击 `启动系统.bat`；或在目录下执行 `python main.py`。
- 首次启动会自动在 `data/` 下创建 5 个 Excel 数据文件和示例数据。

## 三、内置账号

| 角色 | 用户名 | 密码 |
|---|---|---|
| 教师 | teacher | 123456 |
| 学生 | student | 123456 |

教师可在“账号管理”中新增/停用账号、重置密码。

## 四、学生端功能

- **知识点训练**：选 科目→章节→知识点 开始做题，单题即时判分；答错展示详细解析，可点“再出类似题”，掌握度≥80 该知识点过关。
- **模拟卷训练**：设置难度系数（1~5）与题量，系统按难度配比随机组卷。
- **高考真题**：按试卷列表作答历年真题（内置示例卷，老师可持续录入补充）。
- **错题本**：自动归集答错题目，一键重做。
- **学情看板**：知识点掌握度画像（最薄弱的排最前）、总览统计、按遗忘曲线（1/2/4/7/15/30 天）的复测提醒与复测。

## 五、教师端功能

- **试卷识别录入**：上传试卷文件（扫描件 PNG/JPG、Word、PDF），点击“开始识别”：
  - 已配置大模型 API：自动把试卷识别为结构化题目，并按科目/题型/知识点分类打标；
  - 未配置 API：演示模式（仅支持带题号的 docx/txt 文本，按题号切分，答案需人工补全）。
  - 识别结果在表格中逐题校对（双击编辑），确认后“写入题库”存到 questions.xlsx。
- **题库管理**：按科目/题型/关键词查询，双击编辑、删除。
- **知识点维护**：维护“科目→章节→知识点”树。
- **账号管理** / **API设置**：管理师生账号；配置大模型 API（base_url、API Key、文本模型、视觉模型）。

## 六、数据文件（data/ 目录）

| 文件 | 内容 |
|---|---|
| users.xlsx | 账号/角色 |
| questions.xlsx | 题目主表 + knowledge_points 知识点树子表 |
| papers.xlsx | 真题卷/模拟卷 |
| records.xlsx | 作答记录/错题 |
| mastery.xlsx | 知识点掌握度画像 |

每次写入前自动生成同名 `.bak` 备份。要重置系统：删除 data 目录后重新启动即可。

## 七、模块结构

```
main.py          程序入口 + 登录窗口
excel_store.py   数据访问层（5 个 Excel 文件统一读写）
engine.py        核心引擎（判分/掌握度模型/组卷算法/复测调度）
study_loop.py    学习闭环（作答处理/相似题/过关/复测）
analytics.py     学情分析（掌握度画像/薄弱点/总览）
ai_recognize.py  大模型识别模块（文件解析/调用API/分类打标/演示模式）
student_ui.py    学生端界面
teacher_ui.py    教师端界面
test_system.py   自动化验证脚本（python test_system.py）
```
